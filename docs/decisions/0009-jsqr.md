# 0009 jsQR (QR scanning in the browser)

Date 2026-09-30 · Scope: "Join with a QR code" on laptops (common.js `K.scanQr`, vendored `vendor/jsqr`) · Status: keep, **use the platform first**

**Needed for:** decoding a QR code from webcam frames (`getUserMedia` is platform-provided).

**Platform (MDN browser-compat-data, 2026-09-30):** `BarcodeDetector`, a standards-track Shape Detection API, is in:

| Browser | Support |
|---|---|
| Chrome Android | yes |
| Chrome desktop | ChromeOS and macOS only |
| Edge | macOS only |
| Firefox | no |
| Safari 17 | behind a preference |

So on **Windows and Linux**, our desktop targets, no browser provides it. A fallback is required.

**Dependency check:**

| Criterion | Evidence |
|---|---|
| Releases | 1.4.0 on 2021-04-24; last commit 2021-08-24 |
| Maintainers | 0 active in the last 12 months |
| Security policy | none |
| License | Apache-2.0 |

**Fails** the releases and maintainers criteria. Risk is limited: it decodes camera frames inside the page's sandbox,
and its output (the invite) is parsed and checked by our own code.

**Decision:**
- Keep as the fallback: the web policy prefers graceful degradation, but here the degraded path (typing the code) is
  already offered.
- Change `K.scanQr` to use `BarcodeDetector` when it exists, and load jsQR only when it doesn't.

**Revisit:** when Chrome/Edge ship `BarcodeDetector` on Windows/Linux, or if a maintained decoder appears.

Sources: https://github.com/mdn/browser-compat-data/blob/main/api/BarcodeDetector.json · https://www.npmjs.com/package/jsqr · https://github.com/cozmo/jsQR
